# Optional product photos

The website works without photos because it includes illustrated fallback artwork.
To use your own product photography, add these files to this folder using these exact names:

- `emb-floral.jpg` — red floral baby dress
- `emb-b116.jpg` — black and copper braid border
- `emb-b24.jpg` — olive grid border sheet
- `emb-b31.jpg` — diamond filigree border sheet
- `emb-es10427.jpg` — black Panjabi neckline set

Use photos you own or have permission to publish. Keep filenames and letter case exact.
